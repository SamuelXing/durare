- #180 should target v3 indexes (117/118); #198 must include queue-wide budget exhaustion (Python #874).
- #199 should account for database timestamps (Go #473).
- #200 now also includes INT4 for datasource step_id (Python #884) and notifications.consumed_by_function_id (Go #499).
- #191/#173 are no longer silently corrupting position counters, but their complete reference capabilities are not implemented. The first-batch regression proves nested transaction/close_stream/write_stream rejection and contiguous surrounding checkpoints.
- Python/Go main removed admin servers and moved Conductor to enterprise components. This does not by itself justify removing durare's admin/Conductor interfaces or closing #197/#182; compatibility decisions should be explicit.
